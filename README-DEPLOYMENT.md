# Deva Medical Center website

This is the self-contained website build for Deva Medical Center. References to the previous hosting domain have been removed; navigation and assets now resolve from this site.

The site is prepared as a DigitalOcean App Platform static site. Connect this folder to a GitHub repository, choose **Static Site**, and set the site domain to `devamc.com` after updating DNS.

The archived contact and search forms are presentation-only because the original server API is not part of this package. They should be connected to a new email or form service before being advertised as working submissions.
